5. Mapa de navegação

Cabeçalho fixo presente em todas as rotas; qualquer página alcança qualquer outra em 1 clique.

  Layout (Header fixo + Footer)
  │
  ├── /                → Sobre Mim      (hero + bio PT/EN + habilidades)
  ├── /projetos        → Projetos       (timeline: antigo → recente)
  ├── /experiencias    → Experiências   (cards empresa/cargo/período)
  ├── /contato         → Contato        (ícones + formulário)
  └── *                → 404            (link de retorno ao início)

  Estado global: idioma (PT/EN) via React Context — persiste ao trocar de rota.
  Ao mudar de rota: o scroll volta ao topo automaticamente.
